Privacy Policy

WonderWalk · Last updated: June 2026

WonderWalk is a GPS-based AI audio guide for Android. This privacy policy explains which data the app transmits, to whom and for what purpose.

Principles

  • No personal user identifiers are collected or stored.
  • The app runs no servers of its own. All data goes directly to public third-party services.
  • Location data is transmitted only as part of search and geocoding requests – never stored permanently on a server.
  • All locally stored data (API keys, history, cache) stays exclusively on the device.
  • There is no advertising, no tracking and no analysis of user behavior.

Data transfers

Google Gemini API (api.gemini.google.com) When you make an AI request or auto mode is active, the app transmits the assembled prompt to the Gemini API. It may contain: POI names, OSM tags, Wikipedia text, Wikidata extracts as well as, optionally, a photo of the POI or a camera image you took yourself.

The API key is stored locally on your device and is not shared with third parties. The Google Gemini API Terms of Service and the Google Privacy Policy apply.
OpenStreetMap Overpass API (overpass-api.de) To search for nearby points of interest, GPS coordinates and the chosen search radius are transmitted to the public Overpass API. No personal data is transmitted. Usage is subject to the OSMF Usage Policies.
Nominatim geocoding (nominatim.openstreetmap.org) To convert GPS coordinates into a readable address (reverse geocoding), coordinates are transmitted to Nominatim. No personal data is transmitted. Usage policies: OSMF Nominatim Policy.
Wikipedia / Wikidata / Wikimedia Commons To fetch articles, facts and media about a POI, requests are made to the public APIs of Wikipedia, Wikidata and Wikimedia Commons. What is transmitted is only the label or ID of the object concerned as well as GPS coordinates for geo searches. No personal data is transmitted.
OpenHistoricalMap API (openhistoricalmap.org) When the OHM data source is enabled, GPS coordinates are transmitted to the OHM Overpass API to search for historical POIs. No personal data is transmitted.
Wikimedia Commons upload (commons.wikimedia.org) If you want to upload photos or audio recordings to Wikimedia Commons, a Wikimedia OAuth2 token is required. This token is stored exclusively locally on your device and is not shared with third parties. On upload, the media file as well as metadata you enter or that is AI-generated (description, categories) are transmitted to Wikimedia Commons. Uploaded content is published under a free license (CC BY-SA 4.0).
Google Play Billing (play.google.com) The Google Play Billing API is used to purchase WonderWalk Pro. The purchase process is handled entirely through Google Play. WonderWalk stores no payment data. The Google Play Terms of Service apply.
GitHub API (api.github.com) At app startup, WonderWalk checks once via the public GitHub API whether a new version is available. No personal data is transmitted.

Locally stored data

The following data is stored exclusively on the device and does not leave it:

  • Gemini API keys – stored in the app settings
  • Wikimedia OAuth token – only if you have logged in
  • AI answer cache – Gemini answers, 30 days, deletable under Settings → Cache
  • Enrichment cache – Wikipedia texts, images, Wikidata extracts, 7 days
  • Ambient soundscape cache – downloaded audio files, 30 days, max. 25 files
  • POI history – already visited and announced POIs
  • UI translations – locally generated translations of the app interface
  • App settings – radius, prompt templates, filters, favorites

All of this data can be deleted entirely under Settings → Clear cache or via the Android system settings.

Permissions

  • Location (Precise & Approximate) – for POI search and auto mode; active only while in use, as a foreground service in auto mode
  • Camera – optional, only if you want to take or upload a photo
  • Microphone – optional, only for audio recordings to upload to Wikimedia Commons
  • Notifications – for the status bar of the foreground service in auto mode
  • Internet – for all API requests
  • External storage (Android ≤ 12) – for the RSS export to the Downloads folder

Third-party privacy policies

  • Google Privacy Policy (Gemini, Play Billing, Play Services)
  • Wikimedia Foundation Privacy Policy
  • OpenStreetMap Foundation Privacy Policy

Children

WonderWalk is not specifically directed at children under 13. The app collects no personal data and is rated PEGI 3 / IARC.
